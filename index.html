تایپوگرافی؛ ۹۰٪ طراحی، متن است

سه قانون فارسی: line-height را بدون واحد و بین ۱٫۷ تا ۲ بگذارید، به‌جای letter-spacing از word-spacing استفاده کنید (حروف فارسی می‌شکنند!) و اندازه را با rem بدهید.

typography.css
body {
  font-family: Vazirmatn, sans-serif;
  font-size: 1.05rem;   /* نه px */
  line-height: 1.9;     /* بدون واحد */
  word-spacing: .12em;  /* نه letter-spacing */
}
h1, h2, h3 {
  font-family: Lalezar, Vazirmatn; /* جفتِ نمایشی */
  line-height: 1.4;
}
.accent-text { text-shadow: 0 2px 12px rgba(255,180,84,.4); }
💡جفت‌سازی فونت: یک فونت نمایشی برای تیترها (اینجا «لاله‌زار») + یک فونت خوانا برای متن («وزیرمتن»). بیشتر از دو خانواده استفاده نکنید.
🧪 متن زنده را تنظیم کنید
طراحی خوب دیده نمی‌شود؛ طراحی خوب «احساس» می‌شود. وقتی تایپوگرافی درست باشد، چشم مخاطب بی‌زحمت روی صفحه سُر می‌خورد و پیام، پیش از آن‌که خوانده شود، فهمیده می‌شود.

Animation و @keyframes

گذار دو حالت دارد؛ انیمیشن بی‌نهایت فریم. صحنهٔ keyframes را تعریف کنید، با shorthand به عنصر بچسبانید و پخش کنید.

keyframes.css
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-52px); }
}
.ball {
  animation: bounce 1s ease-in-out infinite;
  /* name duration timing iteration */
}
.ball.done { animation-fill-mode: forwards; }
@media (prefers-reduced-motion: reduce) {
  .ball { animation: none; } /* دسترس‌پذیری! */
}

طراحی پاسخگو

موبایل‌فرست یعنی استایل پایه برای کوچک‌ترین صفحه باشد و با min-width بزرگ‌ترش کنید. عرض قاب را بکشید تا چیدمانِ نمونه «زنده» واکنش نشان دهد.

responsive.css
/* موبایل‌فرست: پایه برای همه */
.grid { grid-template-columns: 1fr; }

@media (min-width: 768px) {   /* تبلت */
  .grid { grid-template-columns: 1fr 1fr; }
}
@media (min-width: 1100px) {  /* دسکتاپ */
  .grid { grid-template-columns: repeat(3, 1fr); }
}
/* تایپوگرافی سیال بدون media query */
h1 { font-size: clamp(1.6rem, 4vw, 2.8rem); }

Custom Properties و توابع

متغیرها را در :root تعریف کنید، همه‌جا با var() بخوانید، و محلی بازنویسی کنید. یک کلیک روی رنگ‌ها = تغییر آنیِ کل دمو.

variables.css
:root {
  --accent: #ffb454;
  --radius: 14px;
}
.btn {
  background: var(--accent);
  border-radius: var(--radius);
  /* مقدار جایگزین: */
  color: var(--on-accent, #000);
}

نکات طلایی که کلاس‌ها را می‌شکافد

۰۱

box-sizing سراسری: اولین خط هر پروژه — همه‌چیز را قابل پیش‌بینی می‌کند.

۰۲

فونت با rem: با تغییر فونت ریشه، کل مقیاس صفحه عوض می‌شود؛ px این انعطاف را ندارد.

۰۳

!important ممنوع: نشانهٔ جنگ با آبشار است؛ به‌جایش وزن انتخابگر را درست کنید.

۰۴

فقط transform و opacity: تنها خاصیت‌هایی که انیمیشن‌شان ۶۰fps واقعی می‌ماند.

۰۵

:focus-visible را دریابید: outline را هرگز حذف نکنید؛ کاربران کیبورد به آن نیاز دارند.

۰۶

prefers-reduced-motion: بعضی کاربران با انیمیشن‌های زیاد سرگیجه می‌گیرند؛ راه گریز بگذارید.

۰۷

clamp() برای تایپوگرافی سیال: یک خط به‌جای سه media query.

۰۸

نام‌گذاری BEM: card__title--large؛ هم خواناست هم بی‌تعارض.

۰۹

gap به‌جای margin: در فلکس و گرید، فاصلهٔ بین آیتم‌ها کار gap است نه margin.

۱۰

موبایل‌فرست: اول صفحهٔ کوچک، بعد min-width؛ کد کمتر و تمیزتر.

۱۱

DevTools بهترین معلم: تب Computed مدل جعبهٔ هر عنصر را به شما نشان می‌دهد.

۱۲

هر روز یک چیز کوچک بسازید: CSS در «ساختن» یاد گرفته می‌شود، نه در «خواندن».
