CSS دقیقاً چه کار می‌کند؟

🧸

یک عروسک را تصور کنید: HTML بدنِ عروسک است، CSS لباس و رنگ مویش، و JavaScript کاری که انجام می‌دهد (راه‌رفتن، حرف‌زدن). ما در این دوره فقط لباس‌ها را یاد می‌گیریم.

🦴
HTMLاسکلت: عنوان، پاراگراف، عکس، دکمه — چه چیزهایی در صفحه هستند.
👗
CSSظاهر: رنگ، اندازه، فاصله، جای هر چیز — صفحه چه شکلی باشد.
⚙️
JavaScriptرفتار: با کلیک چه اتفاقی بیفتد — موضوع این دوره نیست.

ساختار یک قانون CSS

📮

هر قانون CSS مثل یک نامه است: اول می‌نویسید نامه برای چه کسی است (انتخابگر)، بعد داخل پاکت می‌نویسید چه کار کند (خاصیت و مقدار).

colorچه چیزی

#ffd580چه مقداری
;پایان جمله
}بستن پاکت
  • هر جمله با ; تمام می‌شود — فراموش‌کردنش رایج‌ترین اشتباه تازه‌کارهاست.
  • هرچه بین /* و */ بنویسید، مرورگر نمی‌خواند (یادداشت برای خودتان).
  • CSS «آبشاری» است: اگر دو قانون هم‌وزن به یک چیز برسند، پایینی برنده است.

  padding: 16px;
  border-radius: 12px;

/* چند انتخابگر با یک قانون */

  font-family: Lalezar, Vazirmatn;
}

رنگ‌ها را چطور بنویسیم؟

🌈

#ffb454 مثل کد یک رنگ در فروشگاه است: کوتاه ولی بی‌معنی. hsl مثل توضیح‌دادن رنگ با زبان آدمیزاد است: چه رنگی؟ چقدر پررنگ؟ چقدر روشن؟ — سه لغزنده را بکشید.

رنگ‌مایه (H)35°
غلظت (S)100%
روشنایی (L)66%
hsl(35 100% 66%)#ffb454
🎨یک تم کامل با hsl: رنگ‌مایه را ثابت نگه دارید و فقط روشنایی را کم و زیاد کنید — همه‌چیز هماهنگ درمی‌آید.
colors.css
.a { color: #ffb454; }                /* هگز */
.b { color: rgb(255 180 84); }        /* قرمز سبز آبی */
.c { color: rgb(255 180 84 / .5); }   /* با شفافیت */
.d { color: hsl(35 100% 66%); }       /* آدمیزاد! */
.e { background: linear-gradient(     /* گرادیان */
       135deg, #ffb454, #f07178); }
.f { color: oklch(80% .15 70); }      /* مدرن */
  • کنتراست را جدی بگیرید: متن خاکستری روی پس‌زمینهٔ خاکستری زیباست ولی خوانا نیست.
  • شفافیت رنگ (/ .5) بهتر از opacity است، چون فقط رنگ را کم‌رنگ می‌کند نه کل عنصر را.
  • رنگ‌ها را در متغیر نگه دارید (درس ۱۹) تا تغییر تم یک‌خطی شود.

display؛ عنصر چه‌جور جعبه‌ای باشد

🧱

block مثل آجر است: کل عرض را می‌گیرد و بعدی می‌رود خط پایین. inline مثل کلمه در جمله است: فقط به‌اندازهٔ خودش جا می‌گیرد و کنار بقیه می‌نشیند. مهم: به عنصر inline نمی‌شود عرض و ارتفاع داد!

متن قبل …
جعبهٔ ۱
جعبهٔ ۲
جعبهٔ ۳
… متن بعد
  • block: div، p، h1 — عرض کامل، خط جدید.
  • inline: span، a، strong — کنار هم، بدون عرض و ارتفاع.
  • inline-block: کنار هم می‌نشیند ولی عرض و ارتفاع می‌پذیرد.
  • flex / grid: خودش block است ولی بچه‌هایش را می‌چیند (درس‌های ۱۲ و ۱۳).
  • none: کاملاً حذف می‌شود، انگار اصلاً نبوده. (فرقش با visibility:hidden: آن یکی جایش را نگه می‌دارد.)
💡هر عنصری در HTML یک display پیش‌فرض دارد. وقتی می‌بینید «چرا padding این span بالا و پایین اثر ندارد؟» جواب همین است: چون inline است.

مدل جعبه‌ای؛ هر عنصر یک جعبهٔ کادویی است

🎁

content خودِ هدیه است، padding پنبه‌های دور هدیه، border دیوارهٔ جعبه، و margin فاصلهٔ این جعبه تا جعبه‌های دیگر روی میز. لغزنده‌ها را بکشید.

padding (پنبه)24px
border (دیواره)10px
margin (فاصله)20px
  • padding رنگ می‌گیرد، margin همیشه شفاف است.
  • برای فاصله‌ی داخل کارت padding، برای فاصلهٔ بین کارت‌ها margin (یا بهتر: gap).
  • margin دو عنصرِ زیر هم «قاطی» می‌شود (۲۰+۳۰ می‌شود ۳۰، نه ۵۰) — به این می‌گویند margin collapse.
content — خودِ هدیه
margin — بیرون جعبه border — دیوارهٔ جعبه padding — داخل جعبه content — محتوا

content-box یا border-box؟

📦

می‌گویید «جعبه‌ای به عرض ۲۰۰ می‌خواهم». content-box یعنی ۳۰۰ فقط فضای داخل است و پنبه و دیواره روی آن اضافه می‌شود (جعبه از میز بیرون می‌زند!). border-box یعنی ۳۰۰ کل جعبه با دیواره است. هر دو جعبهٔ پایین دقیقاً همان عرض را خواسته‌اند — لغزنده‌ها را بکشید و تفاوت را ببینید.

💡خط آبی‌چین، عرضی است که خواسته‌اید. ببینید کدام جعبه از آن بیرون می‌زند.

متن؛ ۹۰٪ کار طراحی

📖

متنِ خوب مثل صدای آرام است: راحت می‌رسد. سه قانون فارسی: فاصلهٔ خطوط را باز بگذارید (۱٫۸ تا ۲)، طول خط را کوتاه کنید (حدود ۶۵ حرف)، و برای فارسی به‌جای letter-spacing از word-spacing استفاده کنید — حروف فارسی به هم چسبیده‌اند و از هم می‌پاشند!

🧪 لغزنده‌ها را بکشید
طراحی خوب دیده نمی‌شود؛ طراحی خوب «احساس» می‌شود. وقتی تایپوگرافی درست باشد، چشم مخاطب بی‌زحمت روی صفحه سُر می‌خورد و پیام، پیش از آن‌که خوانده شود، فهمیده می‌شود.

  • تیتر بزرگ = line-height کوچک‌تر؛ متن کوچک = فاصلهٔ خط بیشتر.

تا اینجا برای ساختن یک سایت واقعی کافی است

🏗

جعبه، متن، صف (فلکس) و جدول (گرید) را بلدید. همین چهار تا برای ساختن یک وب‌سایت رزومهٔ کامل کافی است. بروید بخش تمرین‌ها، تمرین شمارهٔ ۱ را باز کنید و گام‌به‌گام با هم بسازیم — بعد برگردید و بقیهٔ درس‌ها را ادامه دهید.

  • در تمرین ۱ چه می‌سازیم؟ یک صفحهٔ رزومه با سربرگ، مهارت‌ها، تجربهٔ کاری و تحصیلات.
  • چطور؟ ۱۲ گام کوچک. هر گام: یک هدف ساده، چند خط CSS، و خروجی زنده کنار دستتان.
  • خروجی هر گام دقیقاً همان چیزی است که در پیش‌نمایش می‌بینید — می‌توانید کد را هم دستکاری کنید.
🎓حرف معلم: CSS با خواندن یاد گرفته نمی‌شود، با ساختن یاد گرفته می‌شود. اگر فقط اسلایدها را ببینید و کد نزنید، فردا هیچ‌کدام یادتان نمی‌ماند. یک گام از تمرین در روز، از ده اسلاید خواندن بهتر است.

🏷

همهٔ عناصر مثل بچه‌ها در صف می‌ایستند (static). relative یعنی «کمی از جایت تکان بخور، ولی جایت را نگه دار». absolute یعنی «از صف بیا بیرون و مثل برچسب بچسب به گوشهٔ والدت» — جایش در صف خالی می‌شود و بقیه جلو می‌آیند!

Transform + Transition

🚪

transform یعنی عنصر را بچرخانی، بزرگ کنی یا جابه‌جا کنی — بدون این‌که بقیهٔ صفحه تکان بخورد. transition همان آرام‌بندِ در است: به‌جای این‌که تغییر یک‌دفعه بپرد، نرم انجام می‌شود.

⚗
  • transition روی حالت عادی بنویسید، نه داخل :hover — وگرنه فقط رفت نرم می‌شود و برگشت می‌پرد.
  • فقط transform و opacity را انیمیت کنید؛ این دو روی کارت گرافیک اجرا می‌شوند و روان‌اند. انیمیت‌کردن width یا top صفحه را کند می‌کند.

Animation و ‎@keyframes

🎬

transition فقط دو حالت داشت: قبل و بعد. انیمیشن مثل کارتون است: می‌گویید در ۰٪ کجا باشد، در ۵۰٪ کجا، در ۱۰۰٪ کجا — و مرورگر بینشان را پر می‌کند.

keyframes.css
/* ۱) فریم‌ها را تعریف کن */
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-52px); }
}

/* ۲) به عنصر بچسبان */
.ball {
  animation: bounce 1s ease-in-out infinite;
  /*         نام   مدت  شتاب      تکرار  */
}

/* ۳) به فکر همه باش */
@media (prefers-reduced-motion: reduce) {
  .ball { animation: none; }
}
توپ
duration1s
♿بعضی کاربران با حرکت زیاد سرگیجه می‌گیرند. همیشه بلوک @media (prefers-reduced-motion: reduce) را بگذارید — سه خط است و برای عده‌ای فرق بین «قابل استفاده» و «غیرقابل استفاده» را می‌سازد.

پاسخگو؛ سایت مثل آب شکل ظرف را بگیرد

💧

آب در لیوان شکل لیوان می‌شود، در بطری شکل بطری. صفحهٔ شما هم باید در موبایل و لپ‌تاپ همان‌قدر خوب باشد. موبایل‌فرست یعنی اول برای صفحهٔ کوچک بنویسید، بعد بگویید «اگر جا بود، دوستونه شو».

responsive.css
/* پایه = موبایل: یک ستون */
.grid { display: grid; grid-template-columns: 1fr; }

@media (min-width: 768px) {   /* تبلت به بالا */
  .grid { grid-template-columns: 1fr 1fr; }
}
@media (min-width: 1100px) {  /* دسکتاپ */
  .grid { grid-template-columns: repeat(3, 1fr); }
}

/* اندازهٔ سیال، بدون هیچ media query */
h1    { font-size: clamp(1.6rem, 4vw, 2.8rem); }
.wrap { width: min(1100px, 92%); margin-inline: auto; }
< 640pxموبایل
640–1024pxتبلت
> 1024pxدسکتاپ
  • این تگ را در <head> فراموش نکنید، وگرنه موبایل صفحه را زوم‌اوت می‌کند:
    <meta name="viewport" content="width=device-width, initial-scale=1">
  • clamp(کف، دلخواه، سقف) جای سه media query را می‌گیرد.

متغیرها؛ یک‌بار بنویس، همه‌جا استفاده کن

🎨

مثل قوطی رنگ با برچسب است: روی قوطی می‌نویسید «رنگ اصلی». هرجا لازم شد از همان قوطی برمی‌دارید. روزی که نظرتان عوض شد، فقط داخل قوطی را عوض می‌کنید و کل ساختمان رنگ جدید می‌گیرد. روی رنگ‌ها کلیک کنید.

variables.css
:root {                    /* قوطی‌ها اینجا */
  --accent: #ffb454;
  --radius: 14px;
}

.btn {
  background: var(--accent);      /* برداشتن از قوطی */
  border-radius: var(--radius);
  color: var(--on-accent, #000);  /* مقدار پشتیبان */
}

.card { padding: calc(var(--radius) / 2); }

دوازده نکته که کارتان را عوض می‌کند

۰۱

اول از همه border-box: *{box-sizing:border-box} — اندازه‌ها دیگر غافلگیرتان نمی‌کنند.

۰۲

فونت و فاصله با rem: تا کاربرِ کم‌بینا هم بتواند صفحه را بزرگ کند.

۰۳

!important یعنی شکست: نشانهٔ جنگ با آبشار است. انتخابگر را ساده کنید.

۰۴

فقط transform و opacity را انیمیت کنید: بقیه صفحه را کند می‌کنند.

۰۵

outline را حذف نکنید: کاربر کیبورد بدون آن گم می‌شود؛ اگر زشت است، جایگزین زیبا بدهید.

۰۶

prefers-reduced-motion را رعایت کنید: سه خط، برای کسانی که از حرکت اذیت می‌شوند.

۰۷

gap به‌جای margin: در فلکس و گرید فاصله‌ها کار gap است.

۰۸

موبایل‌فرست بنویسید: اول کوچک، بعد min-width؛ کد کمتر و تمیزتر.

۰۹

نام کلاس از روی کار، نه رنگ: .btn-primary بله، .btn-orange خیر.

۱۰

طول خط را کوتاه کنید: max-width: 65ch خوانایی را دو برابر می‌کند.

۱۱

DevTools بهترین معلم است: با F12 هر عنصر را باز کنید و مدل جعبه‌اش را ببینید.

۱۲

هر روز یک چیز کوچک بسازید: CSS در ساختن یاد گرفته می‌شود، نه در خواندن.
